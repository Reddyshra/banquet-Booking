The Online Banquet Booking System is a web-based application designed using PHP and MySQL to streamline the banquet reservation process. The system features two main modules: the Admin Module and the User Module. The Admin Module provides a comprehensive dashboard for managing core elements, including services, event types, and static pages (About Us and Contact Us). Additionally, the admin can monitor booking statuses, respond to queries, generate reports for specific timeframes, and conduct searches using user details or booking IDs. The admin also has profile management capabilities, such as updating information and handling password recovery. In the User Module, users can explore available services and conveniently book the banquet by submitting details about their event. This project enhances the efficiency and accessibility of banquet bookings, making it a valuable tool for event management.
